# NLP Lab

This repository contains a Python script for morphological analysis and part-of-speech tagging.

## Setup

1. Install dependencies using uv:
   ```bash
   uv sync
   ```
2. Activate the virtual environment:
   ```bash
   .venv\Scripts\activate
   ```

## Usage

Run the analysis script:
```bash
python word_analysis.py
```

The script provides a command line interface with three options:
1. English word analysis
2. Hindi word analysis
3. NLTK POS tagging

Select an option and input text when prompted.
